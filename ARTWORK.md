# Profile artwork

The space header is adapted from [galaxy-profile](https://github.com/vinimlo/galaxy-profile). Named stars represent public repositories; particle dust is decorative. VisDSR, CPulse Tracker, and YByte are highlighted. Bento and US appear in the README with their private source status.

The header, tool strip, activity card, and contribution animation use black, white, and grey. Desktop and mobile layouts are provided, with dark/light variants and static alternatives for reduced motion.

## Regenerate the header

```sh
python3 -m pip install -r requirements-artwork.txt
python3 scripts/update_galaxy.py --output dist
```

Edit `galaxy.yml` to change the identity or featured public repositories. To reproduce a stored public snapshot:

```sh
python3 scripts/update_galaxy.py --input public-repositories.json --date 2026-10-05 --output dist
```

The profile workflow runs daily and on changes to its renderer or configuration. It refreshes the galaxy, public activity card, and contribution snake, then publishes the SVGs to the `output` branch. The README uses those generated files. A set of header SVGs is also kept in `assets/`.

The repository uses its built-in GitHub token and standard public Actions runner. The galaxy reads public repository metadata through GitHub's public user endpoint. Activity counts are filtered to public repositories; the contribution calendar uses GitHub's displayed contribution data. No private app source or inference provider is used.
