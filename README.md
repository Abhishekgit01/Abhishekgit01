I'm an **Artificial Intelligence and Robotics student at Dayananda Sagar College of Engineering, Bengaluru**. I'm building **Bento** for restaurants in Mysuru, developing **US**, and studying how multimodal models reason through data structures with **VisDSR**.

## Projects

### [VisDSR](https://github.com/Abhishekgit01/VisDSR)

The same DSU problem, presented as text or an image. Comparing Qwen3-VL and InternVL3.5 across five conditions, using a C++ simulator, an independent Python reference, and strict JSON scoring. **Calibration complete; main study in progress.**

### Bento

**Founder · Mysuru · Pre-launch**

A restaurant discovery and dine-in platform, with **7 restaurant collaborations ahead of launch**. Customer app, restaurant dashboard, and backend workflows for payments, reconciliation, and retries. Source code is private.

### [US](https://www.usapp.in/)

A couples app with paired accounts, encrypted messaging, and shared plans. Built with React Native, Expo, TypeScript, and Supabase. [Website →](https://www.usapp.in/) · Source code is private.
